# Money Manager UI Design System

Money Manager is now visually aligned with the design direction of modern One UI: task-focused screens, generous viewing-area spacing, rounded focus blocks, calm backgrounds, consistent iconography, and restrained use of saturated colors.

## Palette
- Brand: `MMGreen` / `MMGreenDark`
- Positive: `MMGreenIncome`
- Expense: `MMRedExpense`
- Warning/due: `MMAmberDue`
- Information: `MMBlue`
- Supporting accent: `MMCyan`
- Background: `MMBackground`
- Surface: `MMSurfaceElevated`
- Text: `MMBlack` / `MMGrayText`

## Components
- `MoneyManagerTopBar` is the shared app-bar primitive.
- `SectionCard` is the standard focus block for dashboard content.
- `IconBadge` is the standard rounded icon container.
- `CategoryVisual` is the category-specific 3D-inspired icon/photo container.

## Principles
1. Keep the primary task visually dominant.
2. Use one strong brand color rather than coloring every component.
3. Reserve red/amber/blue for meaning, not decoration.
4. Prefer rounded surfaces and low elevation over heavy borders.
5. Constrain long text so numeric columns never move.
6. Keep interactive actions reachable near the lower portion of the screen.
7. Preserve a consistent structure between light and dark modes.
